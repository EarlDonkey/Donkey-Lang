Bare-Metal x86-64 NASM

Pratt Precedence Parser

Donky-Lang Language Reference

Official documentation for standard library builtins and VM directives.

Built-in Network Functions
  • tcp_listen(port) - Bind server socket
  • tcp_accept(server_id) - Accept client connection
  • tcp_read(client_id, max) - Read raw byte buffer
  • tcp_write(client_id, msg) - Send raw payload
Memory & String Builtins
  • byte_at(str, pos) - Read ASCII byte integer
  • byte_substr(start, end) - Slice string buffer
  • bytes_to_str(byte_array) - Convert byte vector
  • split(str, delimiter) - Tokenize string to array
