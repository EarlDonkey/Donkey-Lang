# Donky for VS Code

Syntax highlighting and language support for the [Donky programming language](https://github.com/EARLDONKEY/Donkey-Lang).

## Features

- Syntax highlighting for `.donk` files
- Auto-closing brackets and quotes
- Comment toggling with `Ctrl+/`
- Bracket matching
- Automatic indentation inside `{ }` blocks

## Planned

- Diagnostics (errors and type warnings as you type)
- Completion (keywords, builtins, defined names)
- Hover (function signatures, variable types)
- Go-to-definition
- Document outline

## Development

Open `editor/vscode/` in VS Code and press `F5` to launch an Extension Development Host with the extension loaded.

For a permanent install without F5, see the parent repo's `editor/README.md`.
